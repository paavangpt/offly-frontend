# Frontend Design

Build memorable, functional interfaces with a clear aesthetic direction. Focus on bold typography, cohesive palettes, purposeful motion, semantic structure, and accessibility.

## Workflow
- Identify purpose, users, platform constraints, framework, tone, and content types.
- Choose one memorable visual gesture. See `references/aesthetic-playbook.md`.
- Define palette, fonts, shadows, radii, spacing, and motion tokens.
- Use focused React components, semantic markup, labels, skip links, and descriptive alt text.
- Prefer CSS Grid for page layout, Flexbox for component clusters, and purposeful backgrounds and borders.
- Use a few brief animations and respect `prefers-reduced-motion`.
- Check responsive behavior, visible focus, AA contrast, labeled inputs, and `aria-live` status.
